# Gardner Kiosk Frontend

React + Vite frontend for the Gardner Hall kiosk interface.

## Scripts

- `npm run dev` starts the local Vite development server.
- `npm run build` creates a production build.
- `npm run preview` serves the production build locally.
- `npm run lint` runs ESLint.

## Notes

- API calls use `VITE_API_BASE_URL` and default to `http://localhost:8081` when not set.
